# Real-Time with WebSockets

An intermediate project that teaches real-time, bidirectional communication. You build a Node WebSocket server that streams robot telemetry and accepts control commands, and a typed React hook that consumes it with reconnection and backpressure awareness. The foundation for low-latency dashboards.

Built step-by-step with [KhwajaLabs Build](https://khwajalabs.com).

## Stack
- TypeScript
- WebSockets
- Node.js
- ws
- React
